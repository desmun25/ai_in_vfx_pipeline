AI in the VFX pipeline

A running series of head‑to‑head tests, comparing AI tools against the traditional methods they're trying to replace, at each stage of a VFX pipeline: keying, environment lighting, and 3D model generation.

About this research

Each test here follows the same shape: a traditional VFX technique is pitted against an AI tool aiming to do the same job, using the same source material wherever possible, and judged as objectively as the task allows. Some tests score the result numerically; others come down to a single clear verdict.

The aim isn't to declare AI tools universally better or worse than the methods they're replacing, but to find out, test by test, where each one actually holds up in a real production pipeline.
